# postman-api-test-demo
手工接口测试实践项目，使用Postman进行接口测试、用例设计、SQL数据校验
## 项目简介
基于Reqres开放用户接口完成接口手工测试，学习并落地等价类划分、边界值分析、错误推测等测试设计方法；输出测试策略、测试用例、缺陷清单、Postman请求集合。
> 适合展示接口测试基础能力、测试用例设计能力，用于测试岗实习简历项目。

##  被测接口
1. GET 查询单个用户
2. GET 用户分页列表
3. POST 创建用户
4. PUT 更新用户信息

## 测试设计思路
本项目拒绝无脑点点接口，有策略地设计用例：
1. 等价类划分：区分有效、无效输入，覆盖正常和非法入参；
2. 边界值分析：针对分页page参数，验证极限页码；
3. 错误推测：覆盖缺失必填字段、不存在资源ID等开发易漏校验场景；
4. 校验目标：核对接口状态码、返回数据，识别参数校验缺失等质量缺陷。
